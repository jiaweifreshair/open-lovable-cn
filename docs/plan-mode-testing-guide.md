## 🔧 调试技巧

### 查看 Plan API 响应
```javascript
// 浏览器 Console
console.log('[Plan] Response:', {
  content: planContent.substring(0, 100) + '...',
  summary: planSummary,
  manifestCount: suggestedManifest?.length
});
```

### 查看 SSE 数据流
```javascript
// 在 generateTechnicalPlan 中添加
console.log('[SSE] Received:', data.type, data);
```

### 查看后端日志
```bash
# 服务器日志
tail -f start_next.log

# 错误日志
tail -f start_err.txt
```

### 检查网络请求
1. 打开浏览器 DevTools
2. 切换到 Network Tab
3. 筛选 `generate-ai-code-stream`
4. 查看 Request/Response
